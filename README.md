# Mystery Times

An interactive Victorian-style detective mystery game developed using HTML, CSS, and JavaScript.

## Overview

Mystery Times is a browser-based detective game presented as a vintage newspaper. Players investigate a murder case by examining clues, reviewing witness statements, identifying suspects, solving riddles, and answering questions to uncover the murderer.

## Features

* Interactive detective gameplay
* Suspect investigation system
* Hidden clues and puzzles
* Answer validation mechanism
* Detective notes section
* Victorian newspaper-inspired interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
